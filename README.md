# WooCommerce Customer Retainer

WordPress plugin for SMS-based cart retention and customer recycling on WooCommerce stores. Helps recover abandoned carts and re-engage customers through scheduled follow-ups.

## Features

- SMS retention workflow for WooCommerce carts
- Admin dashboard for managing retention records
- Cron-based automated processing
- Configurable plugin settings

## Requirements

- WordPress 6.3+
- PHP 7.4+
- WooCommerce (active)

## Installation

1. Upload the `woo-customer-retainer` folder to `wp-content/plugins/`.
2. Activate **SMS Retention System** from the plugins screen.
3. Configure settings from the plugin admin menu.
